# Report Builder — máquina, não modelo

## Por que este passo existe
PRD, spec e notas já existem. Falta grampear num Markdown estável.
Se um modelo escrevesse o relatório, a nota poderia mudar sem finding nova.

## Trabalho (um só)
Formatar o parecer final. Sem julgamento novo.

## O que isto NÃO é
Não é um agente de IA. Não chama OpenAI. Não altera scores.

## Output
```json
{ "prd": {}, "spec": {}, "results": [], "markdown": "# Relatório Cast Review\\n..." }
```
